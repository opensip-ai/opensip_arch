67: ## Migration constraints
68: 
69: A future reviewed transition must preserve tracked intent, the same no-write
70: pre-initialization value, per-value provenance, historical identities/custody,
71: and promised offline behavior. It must distinguish:
72: 
73: - distribution migration from user-custody state migration;
74: - management-only core adoption from installation of an authoritative closure;
75: - immutable coexistence from in-place package mutation;
76: - removal from explicit purge; and
77: - replay pinning from contract-approved typed degradation.
78: 
79: No migration silently downloads, refreshes an index, mutates a lock, creates
80: replacement historical identities, rewrites evidence meaning, or treats
81: telemetry/network as required.
