## Review refresh rule

Refreshing this matrix requires regenerating the baseline, resolving every row,
and recording the five-lane review disposition in the central register. A hash
match alone is insufficient: a pin is not a selector reader, a pass is not an
application, and an application is not a freeze disposition.
