For each unsatisfied evidence requirement, preview emits one unmet precondition using the existing `REPAIR.EVIDENCE_RUN_UNAVAILABLE` code. Here the code means that the evidence Run cannot supply the evidence required by this repair; it does not assert that the Run has been purged or lost. Retention or replay-assurance failure and per-requirement insufficiency share that code and are distinguished by their remedies. The requirement entry's remedy carries its relation, minimum resolution, evidence plane and exact deficiency; it must distinguish different causes. `EvidenceRequirement.deficiency` remains the typed cause carrier. An empty `unmetPreconditions` array is not a conforming projection when a requirement is unsatisfied, even if the schema alone admits that shape. Neither a different code per deficiency nor a new public code is required. The evidence authority, `applicable=false` and exact `repairPlanId` authorization binding are unchanged.
