## Preventing paper-only completion

- Every decided value has units, domain, equality/overflow behavior and an owner.
- Every state machine has crash/abort/retry behavior and authority boundaries.
- Every interface has producer, consumer, validation and error ownership.
- Positive examples accompany refusals: a system that refuses everything fails.
- Contract-level model checks test independent expected results; product tests
  and qualification are never claimed from a reference model's passing result.
- New contracts explicitly enumerate superseded reservations and incorporated
  source clauses. A new document cannot implicitly apply a rejected artifact.
- A passing final count is necessary, not sufficient: the integrated design must
  answer an implementer's first end-to-end build and failure questions.
