# Proposed stage schema structural profile

FROZEN PROPOSAL, NOT SELECTED. This proposal replaces ambient Draft202012Validator.check_schema format assertions with validation against eight exact bundled Draft2020-12 default meta-schema resources, explicitly format-annotation only. Stage registration still checks exact producer tree membership, raw digest, parse under current integer JSON profile, object plus exact root $schema URL, and typed output declaration. Pretty bytes remain valid when registered. Unknown keywords and nested boolean schemas remain valid; producer references are not fetched. The product identity schema engine is not substituted.

Named compatibility change: malformed pattern strings and patternProperties names such as '(' move from DOCUMENT_INVALID to structurally admitted schema metadata. Registration does not certify regex compilation or instance execution. Any later execution/instance-validation owner must declare its own deterministic regex dialect and fail closed on unsupported/invalid executable schemas before claiming validated outputs. No such execution is newly implemented by this proposal. Existing concrete output-domain validators remain mandatory and unchanged. This is an explicit reviewable change, not equivalence with the former helper.

Fixed patterns actually present in the bundled meta-schema remain assertions. Their selected Python-reference semantics include one trailing LF accepted by ASCII anchor strings and the final-fragment guard; this profile retains those observed fixed-pattern semantics. It does not inherit a general Python producer regex language. The primitive projection experiment documents this boundary; it is not the reference helper or proof of a general validator.

Format-Annotation permits opt-in assertion behavior under the JSON Schema specification; disabling assertions here is an explicit OpenSIP portability choice. Source: https://json-schema.org/draft/2020-12/json-schema-validation sections6.3.3 and7.2.1. No optional Python package may alter this selected profile. Missing/corrupt bundled reference data is a tooling failure, never document admission.

The identity helper preserves all other selected predecessor behavior, including recognition and ASCII predicate addresses.
