# Bounded ACL attribute decoding413 — private experiment

Implement allocation-free structural decoding of the exact native fgetattrlist request used by audit411: RETURNED_ATTRS plus EXTENDED_SECURITY, FSOPT_REPORT_FULLSIZE, into a caller-owned buffer. Return NotReturned distinctly from an explicitly supplied native ACL. The former cannot imply an empty ACL or authorize custody. Positive filesystem support alone is still not a complete proof of every absence case. Decode borrowed ACE claims with bounded count/length/offset checks, without resolving UUIDs or granting writer/actor/custody standing. Unknown flag/right semantics remain the later qualified policy decoder's obligation; structural success does not classify them.

This supplies no new syscall adapter, replaces no existing descriptor_acl path, admits no runtime/profile or caller budget, and is not selected source. SDK C probe confirms header44/ACE24/entry limit128 and native positive1ACE response100bytes; pure Rust tests use synthetic layout bytes and claim no native provenance. The later producer must retain actual descriptors and account all capture, resolution and recheck work under the shared attempt. An inventory/source review is needed before any product integration.
