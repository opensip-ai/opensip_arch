## What the unit does

The feature is only `crash-matrix = []` on `opensip-platform`. No other manifest names it. `src/lib.rs` carries `#[cfg(all(feature = "crash-matrix", not(debug_assertions)))] compile_error!(…)`. `opensip_platform::crash_barrier` is `#[doc(hidden)]` and compiled only with the feature on macOS or Linux. The macros are always compiled. Without the feature a point is `{}`, a wrapped point is its effect, a gate is its wait, a draw is its draw, and a scope is its block.

The barrier holds item 5's 25 scopes between `// BEGIN/END X9 SCOPE REGISTRY`, with `x4.observer` and `x6.recover` read-only. `x9.selftest` and `x9.selftest-observer` exist only under `#[cfg(test)]`, outside that block. Tracing is on exactly when `OPENSIP_X9_ARMS` is present. Empty arms are a census. Arms without `OPENSIP_X9_CHILD` exit 86. A reached point writes one `X9|pid|thread|n|name#k|event|payload` line of at most 512 bytes under one lock. `hold` inserts the point, writes `held`, and blocks in `read(2)`; one held thread reads stdin and delivers each resume through a condvar. `fail-before` and `fail-after` return `EIO` (or the caller's fault) without or after the effect. `torn` writes the first half, then holds, and a resumed torn write returns `EIO`. `.after` runs only after the effect returns `Ok`.

`MatrixChild::spawn` is `current_exe() --exact <entry> --nocapture --test-threads=1` after `env_clear`, then only `OPENSIP_X9_CHILD`, `OPENSIP_X9_INPUT`, `OPENSIP_X9_ARMS` when the child is traced, and `TMPDIR`. The entry `matrix_child` is an ordinary `#[test]` that returns immediately unless `OPENSIP_X9_CHILD` is set. Death is `Child::kill` (`SIGKILL`), then wait and stderr to EOF. `verify_death_at` requires signal 9, a `held` record at that point, and no later record from the holding thread or any durability point. `verify_finished` requires exit 0, the stdout line `running 1 test`, no harness-error, and every arm reached. A missing arm is `HARNESS-ERROR`, never a pass. The watchdog is 300 seconds on `recv_timeout`; expiry only kills and yields `HarnessError::Watchdog`. The test-only constructor shortens it. The no-sleep pin over the macros, barrier, driver, and self-tests admits that one `recv_timeout` and no sleep, poll, or other timed wait.

Platform points sit on the native syscall and on `NativePublication` / `NativeNewPublication`: `create` (exclusive regular, exclusive directory, charged forms, `replace_with` staging), `write` (`NativePublication::write` and `write_at_zero`), `file-barrier`, `rename`, `directory-barrier`, `link` (the `RENAME_EXCL` / `RENAME_NOREPLACE` publication), `reopen-confirm`, `lock`, and `unlock`. Test-injected `PublicationOps` have no points. Featureless expansions of those wraps are the previous expressions: the same `openat` / `mkdirat` / `renameat` / `renameatx_np` / `flock` / chunked `write_at` from offset zero, with the same `EEXIST`, short-write, and error mapping outside the wrap. `write_at_zero` and `native_file_sync` are the previous loops and `F_FULLFSYNC` / `sync_all` moved out so the macro can call them.

The self-test workload reaches 42 durability points (the accounted `create` twice, every other instrumented step once, each `.before` and `.after`). The kill set is those 42 at `#1` plus the second accounted create, 44 entries. `Census::kill_set` uses `#1`, `(n+1)/2`, and `n`.

`tools/check_crash_matrix.py` is stdlib and read-only. `check` requires both repetitions, canonical `opensip.x9.required-runs.v1` / `opensip.x9.run.v1` / `opensip.x9.matrix.v1` JSON, verdict `PASS`, labels and script and expected equal to the required row, the reviewed clean commit, dev profile with exactly `crash-matrix`, synthetic fixture labels, process-death exactly when the script kills and that kill is signal 9 with `lastHeld` at the point, a registry census whose derived kill set is fully covered (extra kills outside the census are allowed), release absence, limits L1–L10, and agreement on `normalizedSha256`, trace digests, and the census. `release-absence` scans for `OPENSIP_X9_` and the 25 registry scopes.

## Judgment calls

1. **Feature in platform only.** Accepted. Item 12 puts the feature here. Forwarding and X8's `cfg(any(test, feature = "crash-matrix", feature = "scenario-fixtures"))` gates are X9-1. This diff does not touch them and adds no `crash_matrix_support`.
2. **Point names.** Accepted. A protocol point is `<scope>.<step>` and may end in `.before` or `.after`. A primitive point is `<scope>/<step>.<before|after>` with the nine primitive steps. A `crash_scope!` name that is or extends a registered scope is absolute; any other name is a segment under the current scope. Segments are `[a-z0-9_-]+`. `x3b.append.seal.witness-pending/rename.after` and `x3c.evidence.stage-run_records` parse; a bare scope, a missing phase, and `#0` do not.
3. **Tracing.** Accepted. Presence of `OPENSIP_X9_ARMS`, including empty, traces. Arms without the child variable exit 86, so a stray variable cannot trace a normal run.
4. **Where actions are armed.** Accepted. `fail-before` at `.before`, `fail-after` at `.after`, `torn` at a write's `.before`, `inject-id` only at `x3d.session.execution-draw` (refused at parse otherwise). Kind admission is a harness error in the child.
5. **Injected `EIO`.** Accepted. File-barrier, rename, and directory-barrier return `libc::EIO`. Existing `publication_failure` classifies Rename `EIO` as `Indeterminate` and SyncTemporary as `Unchanged`; SyncDirectory stays `Indeterminate`. The self-test observes code 5 on those stages.
6. **`.after` only after success.** Accepted. A native error returns before `.after`. A busy `LOCK_NB` reports only `lock.before`.
7. **Torn.** Accepted. The first `len/2` bytes go through the same write, then `held` with payload `torn`. Resume returns `EIO`. A failed half write does not hold.
8. **Addressed resume.** Accepted. `resume <name>#<k>` sits beside bare `resume`. Bare `resume` applies only when exactly one thread is held and not yet resumed. The point is registered before `held` is written. One thread blocks in the stdin read; the others wait on the condvar. The two-thread test resumes the observer tick first.
9. **Placement.** Accepted. Points are on the native ops and the native syscall sites, so callers are covered once. `directory_publication.rs`, the macOS ACL append, and the staging cleanup `unlink` are not instrumented. Item 12 does not list them.
10. **Read-only scopes.** Accepted. Only `x4.observer` and `x6.recover` are read-only. A primitive point is durable even inside a read-only scope, because the name contains `/`. A later census can refine this.
11. **Self-test scopes.** Accepted. They are outside the block the checker and the release scan read. A non-test build has an empty `SELF_TEST_SCOPES`.
12. **Where the self-tests run.** Accepted. They are feature-gated tests inside platform, not a new `[[test]]`. The pin allows a one-line `crash-matrix = []`, a one-line forward to `<dep>/crash-matrix`, and `required-features = ["crash-matrix"]`, and refuses default features, dependency tables, and any other mention. The two matrix targets belong to later units.
13. **Watchdog.** Accepted. 300 seconds, with one `#[cfg(test)]` constructor. A 1 second watchdog ends a never-resumed child as `HarnessError::Watchdog`, including for `verify_death_at`.
14. **Unarmed identical to featureless.** Accepted for this unit. The same pinned outcome and tree are asserted in the featureless build, reproduced by an untraced child with zero records, and reproduced by a traced unarmed child. The featureless expansion test evaluates the effect and drops the step and scope literals. No binary comparison is claimed.
15. **Census at X9-0.** Accepted. Item 12 gives the census of the integrated path to X9-1. X9-0 delivers the mechanism, proved on the self-test workload (42 points, 44 kills). There is no commit, recovery, or sweep above platform in this unit.
16. **Record events.** Accepted. Besides `pass` and `held`, the events are `resumed`, `fail-before`, `fail-after`, `inject-id`, `outcome`, and `harness-error`. The last two use point `-`. A held draw writes `pass` with the payload after resume. The child prints `OUTCOME …` on stdout so an untraced run can be compared.
17. **Guard 4's feature build.** Accepted. `opensip-storage` has no feature until X9-1. The refusal is on `opensip-platform`.
18. **Checker shapes.** Accepted. `required-runs.v1.json` is `{schema, runs: [{case, variant, units, labels, script, expected}]}`. `matrix.json` is `{schema, product, runs, census: {points, trace}, killSet, releaseAbsence, limits}`. `--repeat` is mandatory. Process-death holds exactly when the script kills. Coverage requires every kill-set point to be killed; a run may also kill outside the census. A verdict of `HARNESS-ERROR` is refused, so a census point the product no longer reaches fails the check.
19. **Trace digest.** Accepted. Platform has no SHA-256. `Exit::trace` is `<thread>|<n>|<point>|<event>|<payload>` without the pid. The run writer that digests it is X9-1.
20. **Gate form.** Accepted. The macro takes a unit wait: `if !gate { wait }`. `gate` returns true only when an armed hold resumes, so an unarmed gate runs the wait.

## Child protocol

Holds are not dropped or delivered to the wrong thread: registration precedes the `held` record, the parent sends a resume only after it has seen that record, and a line names a point only while that point is held and not yet resumed. Two holders were resumed in order, and a bare `resume` with two holders is a harness error. Harness errors exit 86 and fail `verify_finished`. An armed point that is never reached is `NotReached`. A primitive outside any scope is a harness error when traced and ordinary publication when untraced. The source pin and the module itself contain no sleep and no timed decision except the watchdog, whose only result is a harness error.

Kills replayed on this host: at `replace/rename.after` the new bytes are visible and the death check passes; at `write.before` the empty staging file remains; at `lock.after` the flock is busy until the process dies and free afterwards. Torn writes leave the first half, and a resumed torn write fails the publication as `WriteTemporary` / `Unchanged` with `EIO`.
