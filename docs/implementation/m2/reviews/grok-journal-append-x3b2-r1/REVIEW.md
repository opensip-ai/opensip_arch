## Judgment calls

1. **Placement.** Holds. `append` is a macOS child of `carrier_floor`, beside `start`, and reuses the private file protocol, `configure_writer`, `same_file`, and `committed_tail`.
2. **One lock per carrier.** Holds. `after_start` consumes `CarrierStart`. There is no process-global registry.
3. **Level 4 is tried.** Holds. `WouldBlock` at `begin` or `acquire` is `LockOrder` on `CarrierRow::Invariant`. `Poisoned` is `Undetermined`. `acquire`'s refusal drops the transaction, so the refusal holds nothing.
4. **SEAL-path release.** Holds. A certain failure leaves the journal transaction for `Drop`, which releases level 4 and then rolls level 3 back. The SEAL hold stays with the caller.
5. **Re-admission.** Holds. Inside `BEGIN IMMEDIATE` the writer re-admits definitions, the format row, and the binding, then requires the committed tail to equal the lock's tail. `Consistent` and `Revert` proceed. `Revert` is a `PENDING` witness at `seq + 1`, the state a certain `INSERT` failure leaves; the next `PENDING` overwrites it. `Advance` and `Initialize` are `ProtocolViolation`. `Quarantine` keeps its kind.
6. **Certain and undetermined.** Holds. The `PENDING` rename, barrier, and confirmation are undetermined. A refused `INSERT` is certain and the open transaction rolls back on drop. Any `COMMIT` error is undetermined with the transaction still open. Every failure of the `COMMITTED` publication is undetermined, including one before that rename. The flag that makes a later budget error undetermined is set only once the effect callback has started; the reservation is charged before that callback, so a short ledger returns `Refused` on the budget row with nothing written.
7. **Latch.** Holds. An undetermined outcome sets the lock flag. Later `begin` refuses `Undetermined`. `reconcile_undetermined` requires the latch, refuses while the mutex is held, calls `reconcile_after_uncertain`, and does not clear the latch.
8. **S6 per lock.** Holds. `revoked` is set only after that lock's `REV` commits. A `REV` in an earlier operation's history is not this lock's latch. Whole-generation closure is absent, as r7.
9. **Invariant row.** Holds. `WrongCarrier`, `LockOrder`, `NoUncertainOutcome`, `AfterRevocation`, `Capacity`, `TerminalSlot`, and `Record` map to `CarrierRow::Invariant`. The comment names the existing triple `SYSTEM.OUTCOME.ILLEGAL_STATE` / `host-invariant` / `HOST.INVARIANT_VIOLATED`, which is already in `common-v4.schema.json` and `public-detail-registry.v1.json`. `Undetermined`, `Open`, `Insert`, and `Commit` are `HostIo` (`HOST.IO_FAILURE` / `host-io`), matching item 8's I/O row, which includes durability-undetermined. 10. **Capacity and TERMINAL.** Holds. The slot checks run before `build_record`'s effect. `projectPurge` remains admitted by `terminal_body` and is not a cause this builder emits.
