## 3. Observations on the model (Low; the prose is right, the evidence is thinner than the prose)
- **O-1 — the recovery issue-order guard is not modelled.** `produce()` has no authority-root input. Probe CE-1: a staging whose replacement root is "issued" 2019-01-01 — years before any authority root — **PROCEEDs**. Since this guard is the one *new* admission rule the document introduces (the "explicit extension of S5"), it should have an input, a refusal and a variant (`replacement-issued-before-authority`, `replacement-issued-after-expiry`).
- **O-2 — the table's fourth row is unreachable through the producer.** `evaluate('abort', …)` returns `operation-kind`; there is no operation that yields `payload=None`. The kernel itself behaves as the row says (my check: no source, plausible wall ⇒ PROCEED writing F/anchor only; wall beyond L + 90 d ⇒ `CLOCK-EXCURSION-FORWARD`, no write). Add a `no-source` operation that passes `None` and assert "never writes L", so the row is exercised and nobody later routes ABORT through a fabricated witness. (The refusal case is the already-accepted consequence of r8 N-1: a time-dependent ABORT on a long-offline install waits for an import or S4.5.)
- **O-3 — `T` is not represented.** "repeat preserves L and T" asserts only that `lastAccepted` is not written; the keep-`T`-on-equal and S4.5-new-`T` rules, which the request singles out, have no model state at all. A one-field provenance token updated by the stated rule (new closure iff `lastAccepted` ∈ writes; S4.5 always) would let both rules and their variants be asserted. S4.5 can stay a stub that only sets F = L and swaps the token.
- **O-4 — coverage of the equality boundary is incidental.** The repeat cases hit witness == L only because the authorization time became L; an explicit `equal-to-L` ordinary case (my CE-3) pins the boundary the keep-`T` rule depends on.
None of these hides or contradicts an owed codec: the document says plainly that typed witness/closure schema and traversal joins are still required, and forbids a scalar-only witness or attestation.
