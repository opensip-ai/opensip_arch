## Required findings

### C1BPLAN-R2-RF-1 (P1): Separate regenerated-output checks from receipt freshness

Location: `docs/implementation/m3/snapshot-plan-c/c1b/PLAN-r2.md:128`.

LD-C1B-7 requires each sub-unit to re-pin and regenerate its affected artifacts, but then requires its census --check to fail specifically because the receipt is stale (also the changes table and section 6:200). The pinned implementation does not have that contract. discovery_census.py:1205-1218 renders a valid receipt with different bindings as outstanding stale rows; run():1373-1379 only compares regenerated bytes with the checked-in output. Once the required regeneration has happened, --check passes even while the receipt remains stale. snapshot_ledger_census.py:283-303 likewise compares generated output bytes, rather than asserting blind-receipt freshness. A failed output comparison is therefore not evidence of the expected stale receipt. As written, the lane cannot satisfy both regeneration and the mandated failure, and treating a comparison failure as expected can hide an actual artifact mismatch.

Required change: Require applicable generated-output --check commands to pass after each sub-unit's re-pin and regeneration. Record the expected receipt-binding mismatch/stale state separately, with exact changed bindings and the relevant published stale status, without relying on private held-out contents. Keep malformed receipts, bad pins, missing artifacts and output differences as failures. Specify a separate freshness assertion if one is needed; do not describe the existing --check as that assertion. After the reviewed final blind refresh, require both current bindings/receipts and passing artifact checks. Update the changes table, LD-C1B-7 and section 6 consistently.

### C1BPLAN-R2-RF-2 (P2): Resolve when the full VCS model and cap evidence become mandatory

Location: `docs/implementation/m3/snapshot-plan-c/c1b/PLAN-r2.md:119`.

The split at line 63 and LD-C1B-7:124 assign the VCS term in snapshot_ledger_model.py to C1b-2. Deferring a physical blind refresh does not itself resolve this model-evidence timing conflict.

Required change: Choose and state one consistent owner and acceptance gate for the complete VCS term. Preserve the full derivation and fixed-cap/2x evidence before C1b-1 acceptance, preferably by assigning its model change to C1b-1 and updating the split and batch inputs accordingly. If a later model integration is intended, explicitly specify how the reviewed final model bytes and full evidence are supplied before C1b-1 acceptance and how they are preserved through C1b-2; do not silently defer the Q1 gate. Make LD-C1B-6, LD-C1B-7 and section 8 agree.
