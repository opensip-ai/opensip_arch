On equality/prefix termination it includes a conceptual length tie-break allowance. Independent byte-index observers gave:

   | operands | byte-index reads | reported bytes | per-comparison allowance |

   This does **not** invalidate the charge. With a mismatch at index i below the shorter length n, the reads are `2(i+2) <= 2(n+1)`; equality/prefix reads are `2n`. That agrees with the imported comparison-price convention at product `crates/host/src/snapshot_admission.rs`:159–166. Cache the differing bytes or count their reread, or qualify “exactly” in the r4 changes/§8. The counter is not an exact observation of byte indexing as currently described, but the upper bound is sound independently of that wording.
