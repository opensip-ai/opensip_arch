## Package and owner keys

Path packages use the existing native rule `sourceId=""`. The schema copies `DependencyPackageSourceV1` bounds: name and version are strings of length 1 through 256, and `sourceId` is a string of at most 4096 bytes, so the empty path value fits. The key is not a Cargo package id, a path, a display label, or a delimiter concatenation. The full tuple stays with the key and is recomputed before a semantic join. Equal keys with unequal tuples are a contradiction. A caller hash does not admit the package.
