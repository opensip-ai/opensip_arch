# RSCP-1 private supplied-stream copy and raw hash primitive

This is a supporting library, not a source receipt or importer. A fixed 4096-byte buffer reads the actual supplied Read to its EOF, updates the closed consuming RawSha256, writes every read byte in order through complete partial-write loops, then acknowledges Write::flush. Only all-success returns plain byte_length and raw SHA256. No named source, stable observation, checksum authenticity, durable filesystem or CAS admission claim follows. An arbitrary caller can construct equal plain data without acquiring any authority.

A caller checkpoint runs before each Read attempt, each Write attempt and each flush attempt, including Interrupted retries. Generic caller errors and underlying Read/Write io::Error objects retain their origin. Zero-progress writes and invalid trait counts fail without loops or invalid slices. Hash length failure is the existing RawSha256 representation limit, not a selected importer source-size cap. On any failure no successful CopiedRaw is returned; already accepted writer prefixes remain provisional and the caller owns cleanup. The helper does not refund logical acquisition charges or manufacture an authenticated undecodable result from a partial hash.

The full importer must charge the actual nonpath source attempt once before raw intake, retain that same attempt across later decode without a second charge, establish actual owned source/copy custody and complete raw checksum correspondence, and retain every original lock/source observation. This helper supplies no source-attempt token, file handle confinement, named-source read fence, mutation proof, no-follow defense, fstat join, atomic publication, filesystem quarantine, SourceCap, owner, activation, context, PlanRunCoverage or CLI route. Copying bytes followed by reopening a mutable path remains insufficient. Caller work/read/write/resource/scratch/cancellation scopes remain mandatory. Checkpoint existence is not proof those scopes are applied. No arbitrary compressed-source limit or numeric IoErrorKind/catalog is added.

Twelve new actual Rust controls cover seven lengths through 65536, three source chunk widths times three writer widths, exact copied preimage and 4096 request bound, standard empty/abc digest vectors, Interrupted reads/writes/flush retry through checkpoints, stops before intake/write/flush and after a provisional prefix, underlying read/write/flush errors, zero progress and invalid trait counts. Faults are injected Read/Write/checkpoint branches, not OS signals, filesystem custody, durable write qualification or giant input. Small test Vec sinks are not retained filesystem observations. Bare Rust controls passed before host checks. Existing code, dependencies, checker, exceptions and closed C3-AG1/decoder/counter/SRH/laws remain unchanged. Separate host tests/Clippy/release/actual host privacy controls/source census and independent review are required before code integration. Inventory successor is prepared only after accepted code is actually present. Full C3a/R3/profile/owner/effective L/product qualification/whole plan remain open.
