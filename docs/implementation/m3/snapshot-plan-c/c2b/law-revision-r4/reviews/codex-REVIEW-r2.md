State exactly which empirical fit claim replaces which prior guarantee, and retain typed refusal outside it. Preserve applicable existing conservative terms where available; do not relabel fixture maxima as sound domain bounds. Also resolve the apparent tension between applying the new formula to all components and keeping object/byte caps unchanged unless a reviewed change is necessary; lower measured values alone should not silently shrink their existing guarantees.
