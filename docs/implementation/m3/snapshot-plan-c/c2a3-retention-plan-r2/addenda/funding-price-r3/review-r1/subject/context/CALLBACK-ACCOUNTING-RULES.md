# Uniform proposed callback source accounting

These rules are proposed for this callback sub-proof only. They are explicit model/semantic trust conditions for independent plan review, not an established completeM or byte bound. They do not authorize hiding arbitrary work in a scalar primitive.

For every named nonleaf source function in CALL-TREE, count argument transport and nonunit return transport separately. A transport of a logical tuple of w active bytes counts both read and write streams, using ceil(2w/64) scalar visits; unit transport has0 bytes/visits. Each visit reserves64bytes. This rule applies equally to extend_from_slice, slice::iter, Iter::new, spec_extend, as_slice/make_slice, append_elements, all reserve forwarding/needs/capacity and all Vec/RawVec pointer forwarding. There is no silent fusion of forwarding wrappers, tail-return values or reserve parameters. A40byte receiver/len/additional/Layout tuple therefore takes2 visits; it cannot be squeezed into one.

Bodies contain explicit scalar primitives/guards plus child call nodes. Field projection needed solely to form a call argument is included once as the input read/output write for that argument; additional source field loads/computations have their own body nodes. A mutable Vec receiver is a thin reference, not a24byte Vec clone. A u8 slice reference and Iter active fields are16bytes conditionally; Layout16, scalar/pointer8 and bool1. Neither private layout padding nor compiler ABI/frame/register/cache traffic is established by these active-field assumptions. Full source/operand proof must test them and every transport boundary, not promote this plan arithmetic.

The finite semantic leaves are explicitly restricted: direct fixed-field/tag/length queries; fixed-arity usize/bool arithmetic/predicates; pointer/reference casts, pointer add/difference; construction of the two active iterator fields; and core slice formation/copy intrinsic semantic operations. No caller-defined helper, variable metadata loop, allocation, grow path, hashing, user comparator or arbitrary closure is a leaf. A scalar leaf has at most16 input and16 output bytes, or three machine-word input pointers/count and unit output; both streams fit64bytes. A direct getter additionally permits one8byte field read where total remains<=64. The copy leaf's payload read/write streams are separately2k, not counted again as metadata. The fixed boolean guard has only its explicit few input flags, not a whole opaque Collector copy.

These language/core semantic leaves include their established correctness/precondition contracts as trusted implementation inputs, as distinct from new logical caller work. Captured raw slice/pointer/UB-check sources show optional checking machinery; the proposal does not claim that machinery is disabled, absent, free in a hardware metric or newly qualified. This is a logical source operation model, not compiler instruction/frame/RSS traffic. A reviewer must challenge whether this declared boundary is compatible with the owning M requirements; if finer core implementation metering is required, return findings and expand the ledger/model before selecting or implementing a fee. No new core primitive authority is silently inferred from the old plan. Source/compiler correspondence and u8 TrivialClone selection remain explicit trust/qualification conditions.

The guard fault tag query is one bounded Option semantic leaf. The begun/finished guard is one fixed two-flag predicate, not a variable loop. Slice incoming length query and its comparison are separate leaves. Iter::new and make_slice both explicitly include the type-is-ZST condition, even for the selected non-ZST u8 path. append_elements explicitly includes count>0. Primitive pointer/slice/boolean input/output tuples are logical active values; all actual wrapper transport is counted by the uniform nonleaf rule. If any purported leaf has more operands, source branches, transport or state than these limits, it must be expanded; the arithmetic model cannot approve it.

Failed paths keep the same callback-entry transport and fault/state/remaining/length leaves plus explicit fail(Some) tag mutation. They perform no extension subgraph. Iterator drop has no user Drop/body or owned element drop; no payload destruction is introduced by a borrowed slice iterator. This says nothing about compiler-created stack cleanup. Begin and finish remain separate local work and retain their full original source/protocol obligations.
