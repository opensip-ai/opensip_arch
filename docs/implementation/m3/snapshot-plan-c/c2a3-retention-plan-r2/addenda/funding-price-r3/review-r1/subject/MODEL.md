# Proposed funding accounting policy

Extend the callback addendum's uniform nonleaf active-field transport model to funding only. The remaining map, collector-local, drop and slot source/operand proofs stay open; this is not an adopted global M model. Do not silently count a caller helper or closure as a leaf. Every source forwarding call in CALL-TREE has separate argument and nonunit return streams, ceil(2*w/64) visits each. Unit carries zero. Scalar word/pointer8, str/Iter16, Map iterator24, one shared closure capture8; logical enum tags are conservatively8 each. These are logical active fields, not native layouts, padding, compiler ABI, instructions, stack copies or RSS. Native premises remain unestablished. No whole ClosureCandidate, BlobRef or Vec header copy is priced when only borrowed.

Reuse the finite callback leaves for fixed field/tag/length queries, fixed-arity scalar arithmetic/predicates, pointer/reference casts/add, two-field iterator construction and core slice formation. A checked arithmetic leaf includes its scalar Option output within16bytes. Explicit fixed tag/payload construction and scalar assignment nodes each touch only their named word/reference, never a whole opaque enum. An enum branch/query is not a loop. usize::max, leading_zeros and u32/u64/bool-to-usize conversions are fixed scalar leaves. The intrinsic usize slice index is expanded into length, comparison, pointer add and reference cast; the enclosing Vec/slice/SliceIndex wrappers are all nonleaf. NonNull conversion/add is within the existing pointer leaf boundary, with its safety contract trusted as before, not a claim optional checking is free hardware work. Unknown/finer core work requires expanding the ledger before acceptance.

All successful path argument/result tuples are <=32 active bytes. A Result carrying usize is tag+word16; a Budget failure is two tags16, wrapped Err24 and ControlFlow::Break up to32. The same failure type is propagated via identity From, with no user conversion or owned error allocation. The map closure is a shared candidate capture plus one borrowed index; its mapped output is a reference. Field projections solely making arguments are part of that transport; additional loads/stores have explicit nodes. No tail/forwarding fusion.

IMPORTANT proposed instrumentation boundary: WorkScope::charge and the WorkLedger scope/latch/counter implementation are the existing trusted accounting mechanism, excluded from application M's recursive self-metering; its caller tuple and caller question-mark are counted. This is a substantive explicit model premise, not an assertion that any cited acceptance already establishes it. Frozen work_ledger.rs exposes the full mechanism, including prepaid/settlement branches. If owning law requires pricing those mechanism bodies in M, reject this boundary and require their source expansion before selecting this fee. No new arbitrary platform helper can inherit this exclusion. An initial refused charge creates no entitlement to run pricing; this proof does not claim its failed metering body is funded by a successful debit. No receipt/custody/profile/cap or allocator primitive authority follows.

ClosureCandidate's fields are private. blob_count is order.len; blobs maps exactly that order iterator, so F values are yielded on completion. ordered/merge_sort construct a permutation of0..blobs.len from initialized integer ranges, only merge those elements, and return no public raw constructor; index accesses are within that candidate invariant. This source relationship is a premise to challenge in the included full component_closure.rs, not a physical fixture or native correspondence claim. Corrupted candidates, invalid unsafe pointers and panic hardware paths are not introduced as lawful funding inputs.
