# Selected schema inputs

`registry.json` is the closed generation registry: exact raw source bytes,
declared document identity/major/profile, handwritten semantic owner, recipe
options/tool closure and globally unique generated outputs. `source-map.json`
records the architecture source pin and namespace/module for every migrated file.
A fragment, reserialized document or filename is not a substitute for that pin.

This integration candidate currently has 28 documents and 586 explicit targets.
Three superseded Native2 handshake definitions and all their subpaths are denied.
Older schema versions remain when selected current records still reference them.
Their exact closure is explicit; generation performs no remote schema retrieval.

This is not yet the final product source selection. Complete TS2/Rust3 wire
owners, the existing common-control schema, the corrected report projection and
fit carrier are still being reconciled. Inert generated carriers are not a CBOR
codec or semantic admission. The report runtime only exposes selected entrypoints;
unselected/superseded raw-schema members embedded for reference closure are not
public validation entrypoints.
