# Coverage source binding experiment01 — unaccepted

The report08/joint09 evidence carrier incorrectly treats one `coverage2` as the
identity of a multi-entry CoverageResultV3 stream. The native producer contract
binds one coverage2 to one registered payload and host subject scope. The actual
retained reference Run names an evidence3 descriptor with two coverage2 IDs.
An envelope's optional diagnostic coverageId cannot identify that collection.

This experiment anchors the panel to `{runId, evidenceId}` and gives every row
its own `{coverageId, descriptor, result}`. It reads the exact admitted Run's
semantic-evidence.coverageIds in their existing canonical order. It never scans
the object map for additional coverage. Identity/count checks inside a document
are distinct from host checks of membership, prefix completeness and native
semantic admission. No new identity recipe is introduced.

`coverage_source.py` is an executable reference correction, not product storage
or a final public carrier. It calls the unchanged complete Run owner and takes
an isolated copy of its test inputs. Production requires the actual admitted
snapshot lease; copying all retained data is not a proposed production strategy.
Loss/corruption propagates the owner's refusal instead of yielding an empty list.
The optional termination coverageId retains its diagnostic meaning independently.

32 checks pass, including four prefixes of the actual replay-admitted synthetic
Run, missing records/payload, corrupt bytes, wrong record kind, exact source
selection, nonaliasing, order, counts and payload/descriptor/schema identity.
Six adversarial documents deliberately pass embedded identity/count checks but
fail the source join. These include another retained evidence descriptor,
self-rehashed unrelated coverage, a nonprefix member, false emptiness and an
RC-6 contradiction. The actual native producer also refuses that contradiction.
An unrelated hash-valid coverage object in the map does not expand the Run set.
These are reference checks; no live analyzer, storage, browser or delivery passes
are claimed. The complete Run fixture is synthetic despite its actual admission.

The adjacent historical-fixture-audit preserves a separate audit: the inherited
shape/join witness has RC-1, RC-6 and deficiency/cause inconsistencies. Its original
builder explicitly declares shape/join-only material. This is not a product
analyzer bug. The new positive rows are read from actual admitted retained bytes;
the old witness was not silently repaired or reclassified.
