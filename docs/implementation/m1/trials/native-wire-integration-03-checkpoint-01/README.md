# Native integration03 — Grok S1 correction

Native02 was accepted by actual Grok within inert integration scope. Its S1 notes
that a non-envelope frame-payload marker is admitted by the IDL guard and only
refused by renderer layout. This successor rejects such unselected marker uses
at IDL admission. A marker is permitted only as the direct payload member of its
own declared envelope. Hidden nullable markers, markers in other fields and
markers used as protocol frame alternatives refuse IDL_PROTOCOL.

This deliberately does not add an unconditional origin-to-envelope edge: for a
valid envelope's payload slot, that would create a spurious self-cycle. The
existing protocol loop expands that slot into its actual payload alternatives,
and ordinary reference cycles still refuse IDL_CYCLE. Four permanent marker
controls cover Grok's exact layering counterexample and related misplaced forms.

Seven guard groups and14 renderer groups pass. Fresh output-h and eight-h match
the prior native02 generated bytes exactly (all eight files). Rust/TS carrier and
codec behavior are unchanged, so prior compiler/reader/runtime evidence applies
to those bytes. No repeated Cargo or71-reader run is claimed. Guard delta review
is still pending. README-native02.md retains parent integration/tool/source limits.
No product installation, source promotion or milestone completion is claimed.
